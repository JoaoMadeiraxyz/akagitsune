# Spec Delta

## Purpose

Defines how a WebSocket connection is accepted by the gateway, how it learns the identity the gateway assigned to it, and which frames end it at admission level.

## ADDED Requirements

### Requirement: Connecting is joining
The gateway SHALL accept WebSocket upgrades on `GET /ws` without any in-band handshake, and SHALL send the new connection a `{"type":"welcome","id":"<uuid>"}` text frame as its first frame, where `id` is a UUID generated by the gateway for that connection. That UUID is the only identity the connection has, and it is the `from` value of every text frame the connection publishes.

Fonte: `src/lib.rs:14` — `app`; `src/ws.rs:38` — `handle_socket`; `src/protocol.rs:8` — `ServerMessage`.
Teste: `tests/gateway.rs:45` — `connection_is_welcomed_with_an_id`; `tests/gateway.rs:52` — `payload_is_relayed_verbatim_to_others`.

#### Scenario: New connection receives its identity
- **WHEN** a client opens a WebSocket to `/ws` and sends nothing
- **THEN** the first frame it receives is a text frame `{"type":"welcome","id":"<uuid>"}` whose `id` parses as a UUID

#### Scenario: Assigned identity is the sender of relayed frames
- **WHEN** a connection welcomed with id `X` sends a valid JSON text frame
- **THEN** the other connections receive it with `"from":"X"`

### Requirement: Frames above 64 KiB terminate the connection
The gateway SHALL accept frames whose payload is at most 65536 bytes. A frame larger than that SHALL terminate the sending connection without a WebSocket close handshake, and SHALL NOT be relayed to any other connection.

Fonte: `src/ws.rs:20` — `MAX_MESSAGE_SIZE`; `src/ws.rs:28` — `websocket_handler`; `src/ws.rs:96` — `handle_socket`.
Teste: none; behavior confirmed by a throwaway probe against a running gateway, not committed.

#### Scenario: Frame at the limit is relayed
- **WHEN** a client sends a text frame whose payload is exactly 65536 bytes of valid JSON
- **THEN** the other connections receive it in a `message` envelope

#### Scenario: Oversized frame drops the sender
- **WHEN** a client sends a text frame whose payload is larger than 65536 bytes
- **THEN** the sender's connection is reset without a close frame
- **AND** no other connection receives anything for that frame
